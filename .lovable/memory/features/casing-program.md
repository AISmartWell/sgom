Пользователь требует страницу в меню с вводом глубин, диаметров, марки стали и цементирования, сохранением по скважине и PDF-отчётом. Утверждены толщина стенки, источник данных, комментарии, схема по глубине и DRAFT. Расчёты прочности не входят в текущий объём.
