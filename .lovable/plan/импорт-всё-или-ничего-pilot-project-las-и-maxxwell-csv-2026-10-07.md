# Импорт «всё или ничего» (Pilot Project LAS и Maxxwell CSV)

## Проблема
Сейчас загрузка LAS сначала удаляет старый каротаж в диапазоне глубин, а потом записывает новые данные частями. Импорт Maxxwell записывает скважины по очереди. При сбое посередине данные остаются частично удалёнными или частично записанными, хотя на экране написано, что частичный импорт запрещён.

## Что сделать
1. Две серверные функции базы данных, каждая выполняется одной транзакцией (при любой ошибке всё откатывается):
   - замена каротажа одной скважины: удаление в диапазоне глубин и вставка всех новых точек;
   - импорт пакета Maxxwell: давление/температура, обводнённость и обсадные колонны для всех скважин файла.
2. Внутри обеих функций — проверка компании пользователя и роли admin/engineer (как сейчас на экране).
3. Pilot Project и Maxxwell Import вызывают эти функции одним запросом вместо цепочки записей.
4. Список «Continue the SPT cycle» показывается только после успешного завершения всего пакета.

## Технические детали
- `replace_well_logs(p_well_id uuid, p_top numeric, p_base numeric, p_rows jsonb)` и `import_maxxwell_batch(p_items jsonb)`, `SECURITY DEFINER`, `search_path = public`, проверка через `user_companies` и `has_role`.
- Ограничить размер `p_rows` (например, до 50 000 точек) для защиты от слишком больших запросов.
- В AGENTS.md добавить правило: пакетные импорты пишут только через транзакционные функции.
